# Implementation and experiment status

This is a small research prototype. The default offline demo, historical schema, chronological evaluation, external affine calibration, model adapter, prompt snapshots and replaceable preference interfaces are implemented. The public source contains synthetic fixtures only.

A local exploratory 100-paper PeerRead ICLR 2017 scoring study used separate 60/20/20 paper groups and one model/settings combination. Raw test MAE/RMSE were 1.1333/1.2826; validation-selected external affine calibration gave 1.1163/1.2351. This small error difference does not establish improved substantive reviewing. The score-balanced sample is not representative; manuscript and rating stages remain unverified, and old public papers may be in model pretraining.

Score prediction is established related work: [PeerRead's released models](https://github.com/allenai/PeerRead/tree/master/code) include manuscript-only, review-only and combined input settings. These are different tasks; a manuscript-only scorer cannot take its own held-out human reviews as input. [CycleReviewer/CycleResearcher](https://proceedings.iclr.cc/paper_files/paper/2025/file/0a48036026dc7946ef6033ae14719cc5-Paper-Conference.pdf) is another relevant line of work. This project does not claim first score prediction or reproduce those systems; its focus is configurable institutional criteria and replaceable model/algorithm/prompt interfaces. No additional upstream training code or model weights were downloaded or run for this release.

A cached scalar-only nonlinear comparison selected raw scores on validation: MAE 1.1625, versus quadratic ridge 1.1748 and a shallow tree 1.1871. It did not collect content-dimension features or make new model calls. The previously viewed test was exploratory and was not used to select a different model.

The AutoCalibrate-style interface is independently implemented from Algorithm 1 of Liu et al., *Calibrating LLM-Based Evaluator*, LREC-COLING 2024, pp. 2638–2656, https://aclanthology.org/2024.lrec-main.237.pdf. Manuscript absolute scores, negative MAE and separate validation selection are task adaptations; this is not official-code reproduction. Two preliminary Sol rule drafts were generated locally; no induced-rule scoring comparison completed. A separate three-paper fixed-TRAIN-history Luna example subsequently verified the existing logged-in route: six calls returned, five passed the original structured contract and one failed exact-quotation evidence validation. No call was repeated. This is a configured conditioning example, not an institutional alignment result; raw outputs and labels remain local. No empirical rule-learning improvement, acceptance probability or successful case study is claimed.

The bounded design uses TRAIN history and candidate-own TRAIN errors for criteria generation/refinement, validation labels only for selection, and frozen criteria before test scoring. Do not turn cross-reviewer absolute scores into fabricated pairwise labels. No base weights are trained. Any new study needs explicit data/model authorization and a fixed budget; old Sol outputs are not a Luna baseline.

Original manuscripts, reviews, individual labels, response caches and local audit artifacts are intentionally absent. Source links, code provenance and required upstream licenses are in the [notices](../THIRD_PARTY_NOTICES.md). Aggregate exploratory values here are not a corpus redistribution or a scientific quality guarantee.
